# checker
Модуль чекера для проекта по "Практическое введение в разработку программного обеспечения"

```
git clone --recurse-submodules https://github.com/byllet/checker.git
```

```
pip install -r src/parser/requirements.txt   
```

Запуск через консоль 
```
python src/cli.py [-h] --input INPUT [--output OUTPUT]
```
